Connection help

Online room codes

Create, join and copy invite codes directly on Home. Everyone uses the same code. P also copies your current code while playing.

LAN play

Run the included server and open its address on each computer. LAN connects automatically and does not use an online room code.

If a connection stalls

Cancel on Home, check your internet connection, then try again. Some networks block public relays; LAN play is an alternative.

The host controls mode and map. Your aim, crosshair and audio stay personal. Public room codes are not private passwords.
